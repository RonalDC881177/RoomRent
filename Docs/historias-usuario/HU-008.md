# Título
Búsqueda avanzada de propiedades

# Descripción

## Como
Arrendatario o visitante

## Quiero
Filtrar las propiedades disponibles mediante diferentes criterios

## Para
Encontrar rápidamente una vivienda que se adapte a mis necesidades.

# Valor para el negocio
Esta funcionalidad reduce el tiempo de búsqueda del usuario y mejora la experiencia de uso de la plataforma, aumentando la probabilidad de que encuentre una propiedad adecuada.

# Criterios de aceptación
- Buscar por ciudad.
- Buscar por tipo.
- Buscar por estado.
- Buscar por rango de precios.
- Permitir combinar filtros.
- Si no existen resultados devolver una lista vacía.
